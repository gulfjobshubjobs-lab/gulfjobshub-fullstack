GulfJobsHub ClamAV runtime setup
================================

Docker deployment (recommended)
1. Install Docker Engine and the Docker Compose plugin on the hosting server.
2. From the extracted project root, run: docker compose -f compose.yaml up -d --build
3. Check startup logs: docker compose -f compose.yaml logs --tail=100 gulfjobshub
4. Confirm scanner exists: docker compose -f compose.yaml exec gulfjobshub clamscan --version
5. Confirm signatures are present/current: docker compose -f compose.yaml exec gulfjobshub freshclam --version
6. Check API health: curl -fsS http://127.0.0.1:3000/api/health

The image installs ClamAV and freshclam. On every container start, freshclam
attempts to update virus definitions before Node starts. REQUIRE_MALWARE_SCAN
is enabled in the image and Compose configuration. CV uploads fail closed if
clamscan is missing, its database is unavailable, or the scanner errors. A
positive malware detection rejects the upload.

Important operational notes
- Allow outbound HTTPS/DNS from the container so freshclam can reach its
  configured signature mirrors. If updates fail, inspect logs and do not open
  CV uploads to users until signatures are available.
- Keep the named gulfjobshub_data volume backed up; it contains app data.
- Put the service behind an HTTPS reverse proxy before public launch.
- Keep the image patched and schedule regular image rebuilds.
- The container's startup update is not a substitute for monitoring signature
  freshness during a long-running container. Configure a scheduled freshclam
  update or restart/update workflow and alert on failures.

Local validation limitation
This project workspace does not have Docker or an installed ClamAV binary,
so the image build and a real malware-signature scan must be performed on the
actual deployment host. Do not describe ClamAV as operational until the
commands above succeed and a controlled EICAR test file is detected by clamscan.
